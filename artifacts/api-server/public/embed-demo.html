Lukas Widget — beliebig designbar

Zwei Live-Beispiele desselben Widgets, nur über data--Attribute unterschiedlich gestylt. Unten rechts in jedem Rahmen den Button anklicken.

Einbindung

<script src="https://DEINE-LUKAS-DOMAIN/widget.js"
        data-api="https://DEINE-LUKAS-DOMAIN"
        data-accent="#e11d48" data-theme="light"
        data-voice="agent" data-agent-id="DEINE_ELEVENLABS_AGENT_ID"
        defer></script>

Voll-Custom per CSS

Das Widget nutzt kein Shadow-DOM — deine Seite kann mit normalem CSS alles überschreiben. Stabile Klassen: .lukas-w .lukas-btn .lukas-panel .lukas-head .lukas-msgs .lukas-m .lukas-m.u .lukas-m.a .lukas-form .lukas-in .lukas-ic .lukas-mic. Beispiel:

.lukas-btn { border-radius: 12px !important; box-shadow: none; }
.lukas-m.u { background: black; }
.lukas-panel { backdrop-filter: blur(12px); }

Stimme (ElevenLabs Agents)

  1. Agent in der ElevenLabs-Konsole anlegen: deutsche Stimme, Sprache Deutsch.
  2. Dort unter LLM → Custom LLM: URL https://DEINE-LUKAS-DOMAIN/api/public/llm/v1, API-Key = dein ELEVENLABS_LLM_TOKEN aus der .env → der Agent denkt mit Lukas' Gehirn.
  3. Agent-ID kopieren → data-agent-id setzen und data-voice="agent".
