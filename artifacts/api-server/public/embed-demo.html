Demo: Lukas auf deiner Portfolio-Seite

Diese Seite simuliert issahareb.me. Unten rechts schwebt der Lukas-Button — anklicken, dann tippen oder aufs Mikro drücken und sprechen.

Einbindung auf der echten Seite mit einer Zeile:

<script src="https://DEINE-LUKAS-DOMAIN/widget.js"
        data-api="https://DEINE-LUKAS-DOMAIN" defer></script>

Öffentlich sichtbares Wissen steuerst du über Erinnerungen mit der Kategorie public (Memory-Seite in der Lukas-UI oder einfach Lukas im Chat bitten, etwas als public zu speichern).
